# mochi-suite

Monorepo of the Mochi projects. Each subfolder was previously its own repository;
full commit history was preserved via `git subtree`.

| Folder | What it is |
|---|---|
| `mochi-lib/` | Shared library / component collection |
| `mochi-academia-planner/` | Pink-pastel university planner (Flask + Supabase) |
| `mochi-planner/` | Earlier planner iteration |
| `mochis-assistant/` | Daily briefing engine — full dashboard bot |
| `mochishub-brief/` | Serverless morning brief, posts to Discord daily |
| `mochi-assistant/` | Earlier assistant prototype |
| `mochi-study-buddy/` | Study companion |
| `mochi-topik-flashcards/` | TOPIK (Korean) flashcards |
| `mochi-pdf-converter/` | PDF conversion utility |
| `mochi-mp3-converter/` | MP3 conversion utility |
